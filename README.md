# formula

Evaluador de fórmulas matemáticas estilo JavaScript, implementado en Java sin
depender de Nashorn.

> **La implementación está en la rama `develop`.** Esta rama (`main`) es el trunk
> estable y solo alojará la documentación del proyecto hasta que se integre.
